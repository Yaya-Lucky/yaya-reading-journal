# 读哈金小说《等待》的思考

刚刚读完哈金的《等待》，有很多问题一直盘旋在我的脑海之中，什么样的生活是幸福的? 我们终其一生到底在追求什么？生活的宁静是由什么构成的？ 
 
贯穿整本书的线索是孔林每年夏天都会回到鹅庄和妻子离婚。他期望能够离婚之后迎娶曼娜，他觉得婚姻应该是基于爱情的，他认为自己和淑玉的婚姻是完全流于形式的。在书中第三章节开始，他十八年来心心念念的事情看似开始得偿所愿。他成功和淑玉解除婚姻关系，他和曼娜举行了轰动整个医院的婚礼，他甚至有了一对双胞胎。如果人生真的这么顺理成章，所得皆所愿，那一切似乎都会变得简单。

# 婚姻，爱情，和家庭
孔林追求爱情，但并不完全清楚自己所求的这个抽象的概念所蕴含的实质性含义。他嫌弃淑玉的小脚， 看不上淑玉的样貌，但是面对年迈需要照顾的父母，他又没有太多反对地和淑玉结为了夫妻，所以他接受没有爱情的婚姻。他认为淑玉没有任何女性魅力，但是他却和淑玉有了女儿孔华，所以他接受没有爱情的性。当曼娜对他展开强烈的追求，想要和他共度良宵时， 因为部队政策的约束，他坚决反对曼娜的提议，如果他认为和曼娜之间的情愫是爱情，那他接受没有性的爱情。当他得知曼娜希望他能离婚时，他自己又颇为震惊，鉴于淑玉在家庭责任承担方面无可挑剔，他此前并没有想和淑玉离婚的想法，所以他尊敬没有爱情的婚姻。当他和曼娜结婚后，读曼娜曾经和另一个人往来的爱情信件时，他思考自己为何不曾有过信中所描述的那种处于爱情之中时，轰轰烈烈的感觉，所以和曼娜的婚姻，或许在某种程度上也不是基于纯粹的爱情。当曼娜心肌梗塞，所剩时日无多时，他又在淑玉和女儿孔华的家里感觉到了温暖和内心的平静，并在酒后希望将来能够回归到这个最初的家庭去生活，此时，他和淑玉有没有爱情已变得不那么重要了。  

孔林只是千千万万人中的一个缩影，我们总是想要拥有美妙的邂逅，理想的爱情伴侣，和谐的婚姻和家庭，但或许我们并不清楚自己想要的到底是什么。我们年轻时深以为然的东西，未必会伴随终身。时间流逝，身体衰老，家庭和社会责任不断累积。那些曾经强烈渴望拥有的东西，往往早已变换了模样。

# 什么是美好的生活
小舅子本生对孔林的看法或许代表着普罗大众对美好人生的定义，受过当时最好的教育，头顶部队军官的光环，家有良妻，儿女双全，集老天垂爱于一生。孔林在当时物质普遍匮乏的时代，医生这份光鲜亮丽的职业使得他的劳动价值的不需要通过下地劳作或者工厂干活来彰显。他的手指白净，未曾受过田间地头的风吹日晒，不曾亲自侍奉过生病的父母，对于女儿孔桦的养育也仅仅停留在每年夏天的短暂接触。日常生活上，和曼娜结婚前，他住在医院宿舍里，不需要亲自洗手做羹汤，就连衣服都有曼娜帮其代劳。和淑玉离婚后，通过卖掉祖宅，获得购置婚房的启动资金，再加上当时部队给已婚军官夫妇分配房产的制度，轻轻松松压垮现代年轻人的房贷问题在孔林身上迎刃而解。当时困扰许多人的子女落户就业问题，在部队政策的优待下，孔林也不费吹灰之力就实现了女儿户口的农转非事宜，并为女儿谋得了一份在火柴厂的工作。如果光从这些角度来看，孔林的生活确实舒服惬意。但当我们纵观全书时，这个知识分子从头到尾都活得压抑憋屈，或许生活的苦从来都不会仅仅体现在物质生活一个层面。

孔林的很多选择帮他度过了很多人生中的危机，但这些选择也为他的郁郁寡欢埋下了伏笔。在家庭责任面前，他选择放弃单身的自由，遵从父母的意志。虽内心为妻子的小脚而羞愧，觉得淑玉拿不出手，但是他也清楚淑玉将来能帮助他扛起照顾年迈父母的重担。所以和淑玉结婚，虽有父母的强迫，但他也没有太多的反对。在社会制度和部队对于婚外情的严苛政策下，他虽喜欢曼娜，但选择克制和压抑自己的情感世界，也告诫曼娜遵守现实礼法以保全两人升职机会。在小舅子本生威胁他，他选择息事宁人以保全在医院的声誉。在得知曼娜被他所谓的朋友强奸后，他选择忍气吞声，沉默不语。和漱玉的婚姻帮助他逃避了赡养父母的责任，但也让他失去了和曼娜光明正大在一起的机会。他的每一次妥协和屈服，让两个家庭陷入了无尽的等待。
